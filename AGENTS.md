# Agent instructions

When a user provides fragments, voice notes, unfinished opinions, or existing copy and asks for an X post, read and follow `SKILL.md`. Do not reinvent the workflow.

Every change to this repository must preserve three invariants:

1. **Idea first** — identify the author's actual claim before optimizing expression.
2. **Human voice** — improve clarity without replacing the author's vocabulary, values, or persona.
3. **No fabrication** — never invent facts, data, quotes, experiences, certainty, or a stronger position than the author supplied.

Keep prompts provider-neutral, keep workflow logic separate from adapters, and run the test suite before declaring a change complete.
