# Contributing

Thank you for helping make Thought-to-X more useful without making it more generic.

1. Fork the repository and create a focused branch.
2. Keep **idea first, human voice, no fabrication** intact.
3. Add or update tests for behavior changes.
4. Run `python -m pytest`.
5. Open a pull request describing the user problem, the change, and an example before/after.

Prompt changes should explain *why* a rule exists and avoid overfitting to one example. Never commit `.env`, API credentials, private writing samples, or generated user content without permission.
