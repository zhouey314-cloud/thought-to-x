我发现自己每天都会冒出大量零碎想法。

以前的工作流是：想到一句话，扔给 AI 润色；觉得太平，再让它按 X 的传播逻辑重写；AI 味太重，又让它改一遍。这个动作一天会重复很多次。

后来我意识到，重复发生的 AI 操作，本质上都应该被做成 Skill。

所以我把这套流程整理并开源了：Thought-to-X。

它先从语音碎片、随手记录或半成品观点里找到你真正想说的东西，再做结构、X 内容优化、去 AI 味和质量检查。它最重要的规则不是“写得像爆款”，而是保留原来的思想和声音，不编数据，不编经历，也不替你升级立场。

仓库里有可直接给 Codex / Claude Code 读取的 `SKILL.md`、模块化 prompts、个人 style profile，也有一个不绑定模型供应商的 Python CLI。没有 API Key 也能直接使用。

Idea First. AI Second.

如果你也经常“想到了，但没写出来”，欢迎拿去改成自己的 X Writer。
