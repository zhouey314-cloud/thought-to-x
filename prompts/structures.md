# 05 Structures

Choose the lightest structure that makes this particular thought clear. Vary shape and pacing; these are options, not rigid templates.

## Observation
Specific observation → what it reveals → restrained implication. Best for noticed patterns.

## Contrarian
Common belief → author's actual disagreement → reasoning → boundary. Use only when disagreement exists.

## Story
Moment → change in understanding → present conclusion. Never invent the moment or details.

## Insight
Core insight early → unpack terms → consequence → position. Best for one strong conceptual claim.

## Experience
What happened → honest reaction → lesson with limits. Use only for supplied experience.

## Question
Real unresolved question → explore competing answers → current leaning. Do not use a rhetorical question as decoration.

## Framework
Problem → small set of distinct parts → how they connect → use. Avoid mechanical listicles when the input has no framework.

## Reflection
Belief or feeling → internal tension → current understanding → quiet close. Preserve uncertainty.

Possible argument sequence: hook → judgment → reason → tension → implication → stance → close. Reorder or omit parts when the thought does not need them.
