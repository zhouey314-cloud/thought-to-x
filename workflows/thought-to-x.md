# Thought-to-X workflow

```text
RAW THOUGHT
    ↓
01 Normalize
    ↓
02 Extract Intent
    ↓
03 Find Core Insight
    ↓
04 Identify Tension
    ↓
05 Build Argument
    ↓
06 Preserve Voice
    ↓
07 X Content Optimization
    ↓
08 De-AI
    ↓
09 Quality Review
    ↓
FINAL POST
```

| Stage | Input | Output | Guardrail |
|---|---|---|---|
| Normalize | raw thought | normalized thought | Preserve thought-bearing detail |
| Extract Intent | normalized thought | intent map | Unknown stays unknown |
| Find Core Insight | intent map | core + supporting insights | One faithful thesis |
| Identify Tension | insights + source | natural tension or none | No manufactured controversy |
| Build Argument | prior artifacts | adaptive outline + draft | Do not force one template |
| Preserve Voice | draft + source + style | voice-aligned draft | No replacement persona |
| X Optimization | voice draft | tighter X draft | No algorithm claims or bait |
| De-AI | X draft | human-sounding draft | Remove patterns, not substance |
| Quality Review | draft + intent | score, gates, revision targets | Fidelity gates are absolute |

Revision loop: when total `< 80` and no hard failure is irreversible, revise the weakest dimensions and repeat stages 8–9. Maximum two revisions.
